# アクティブリーディング管理アプリ 実装プラン

## Context

DaiGo式アクティブリーディングメソッドを実践するためのスマートフォン向けWebアプリを新規作成する。仕様書(`active-reading-app-specification.md`)に基づき、HTML5 + CSS3 + Vanilla JS + LocalStorage + Chart.js で構築する。モバイルファーストのSPA（シングルページアプリケーション）として実装する。

## プロジェクト構成

```
active-reading-app/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── app.js           # メインアプリケーションロジック（ルーティング、画面切替、初期化）
│   ├── storage.js       # LocalStorage操作（CRUD、UUID生成）
│   ├── book.js          # 本管理機能（登録、一覧、詳細、編集、削除）
│   ├── notes.js         # メモ機能（読む前の問い、章メモ）
│   ├── actions.js       # 実践項目機能（追加、完了切替、削除）
│   └── stats.js         # 統計機能（集計、Chart.jsグラフ描画）
```

## 実装ステップ

### Step 1: プロジェクト基盤 — `index.html` + `css/style.css`
- HTML5のベース構造作成
- 各画面のコンテナ（`#home-screen`, `#book-list-screen`, `#book-detail-screen`, `#stats-screen`, `#book-form-screen`, `#chapter-form-screen`）
- 下部固定ナビゲーションバー（ホーム / 本リスト / 統計）
- CSS: カラーパレット（#4A90E2, #7ED321, #F5A623, #F8F9FA, #333）
- CSS: モバイルファーストのレスポンシブデザイン（767px / 768px / 1024px）
- CSS: カード、ボタン（44x44px最小）、フォーム、タブ、バッジ、FABのスタイル
- Chart.js v4 CDN読み込み

### Step 2: データ層 — `js/storage.js`
- `saveData(key, data)` / `getData(key)` — LocalStorage CRUD
- `generateUUID()` — UUID生成
- データキー定義: `books`, `preReadingQuestions`, `chapterNotes`, `actionItems`
- データ初期化（キーが存在しない場合に空配列をセット）

### Step 3: メインアプリ — `js/app.js`
- SPA画面切替ロジック（hash-based routing または関数ベースのナビゲーション）
- 下部ナビのアクティブ状態管理
- DOMContentLoadedでの初期化処理
- 各モジュールの呼び出し統括

### Step 4: 本管理 — `js/book.js`
- 本の登録フォーム（タイトル、著者、カテゴリー → status='before'で保存）
- 本の一覧表示（カード形式、ステータスバッジ、章メモ数・実践項目数表示）
- フィルター（ステータス別、カテゴリー別）、検索（タイトル・著者名）
- 本の詳細画面（基本情報 + タブUI: 問い / 章メモ / 実践リスト）
- 本の編集・削除機能
- ステータス変更（before → reading → completed）

### Step 5: メモ機能 — `js/notes.js`
- **読む前の問い**: 5つのテンプレート質問を自動表示、テキストエリアで回答入力、保存・編集
- **章メモ**: 章追加フォーム（章番号自動インクリメント、タイトル、重要なこと、記憶方法、応用方法）
- 章一覧表示（章番号順）、詳細表示・編集・削除

### Step 6: 実践項目 — `js/actions.js`
- 実践項目の追加（テキスト入力 → 未完了で保存）
- チェックボックスで完了/未完了切替（完了時に日付自動記録）
- 実践メモ追記
- 一覧表示（未完了が上、完了はグレーアウト）
- 削除機能

### Step 7: 統計・グラフ — `js/stats.js`
- 総読書冊数、月別読書冊数、カテゴリー別集計、実践完了率の計算
- 期間選択UI（今月 / 過去3ヶ月 / 過去12ヶ月）
- Chart.js棒グラフ（月別読書数）
- Chart.js円グラフ（カテゴリー別）
- プログレスバー（実践達成率）

### Step 8: ホーム画面の仕上げ
- 読書中の本をカード表示（最大3冊 + 「もっと見る」リンク）
- 未完了の実践項目表示（最大5件 + チェックで即完了）
- 統計サマリー（今月の読書数、実践完了率）

### Step 9: 仕上げ
- アニメーション・トランジション
- バリデーション（必須項目チェック）
- データエクスポート/インポート（JSON形式）
- 全体の動作確認・バグ修正

## 検証方法
- ブラウザで `index.html` を開いて全画面遷移を確認
- 本の登録 → 問い回答 → 章メモ追加 → 実践項目追加 → 完了の一連フローをテスト
- ページリロード後にデータが残ることを確認
- モバイルサイズでのレスポンシブ表示を確認
- 統計画面のグラフ表示を確認
