# Active Reading v2

読んだ本や記事を、本文を見ずに自分の言葉で短く記録し、翌日の任意想起と7日間の行動計画出力へつなげる、端末保存型のPWAです。

## 中心の流れ

1. 本・記事・その他の資料を登録する
2. 読後30〜90秒で自由記述する
3. 翌日に元メモを隠したまま任意で一文想起する
4. ライブラリから使いたいメモを選ぶ
5. AIへ渡す7日間行動計画用Markdownをコピーまたは保存する

アプリ内AI、ログイン、クラウド同期、プッシュ通知はありません。資料・メモ・想起・行動候補はDexie経由でIndexedDBへ保存されます。入力中の下書きだけは、再読み込みから復元できるようLocalStorageへ保存します。

## 開発

```bash
npm install
npm run dev
npm test
npm run build
npm run test:e2e
```

GitHub Pages向けのベースパスは `/active_reading/` です。`main` へのpush時はGitHub Actionsが単体テスト、ChromiumのPC・Android相当E2E、ビルドを実行してPagesへデプロイします。

## 旧版データ

- 初回起動時に旧LocalStorageのデータを検出します。
- 移行前に旧形式JSONを自動ダウンロードします。
- 旧LocalStorageキーは削除しません。
- 決定的な移行IDと移行バージョンを使うため、同じ旧データを再度読み込んでも重複しません。
- ジャーナル、クイズ、読書時間、X投稿、タイマー状態などは読み取り専用アーカイブへ保存します。
- 旧版ソース一式は [`legacy-v1/`](legacy-v1/) にも保持しています。

設定画面から、スキーマバージョン付きv2バックアップの保存、更新日時優先のマージ復元、自動退避後の全置換、旧版JSONの直接インポートができます。

## 保護ポイント

- v2再構築前のGit状態にはローカルタグ `legacy-v1-2026-08-24` を付けています。
- 開発ブランチは `rebuild/v2` です。
- v2は旧Gist同期および保存済みPATを読み取りません。失効と端末側削除の案内だけを設定画面に表示します。
